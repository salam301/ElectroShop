# ⚡ ElectroShop

ElectroShop is a simple and responsive electronics shopping website built using **HTML and CSS**.

The website provides a clean interface to explore different electronic products such as smartphones, laptops, headphones, smartwatches, cameras, and speakers.

## 🚀 Features

- 🏠 Home page
- 🛍️ Explore Products page
- ℹ️ About Us page
- 📩 Contact Us page
- 🔐 Login page
- 📱 Responsive design for mobile devices
- 🧭 Navigation between different pages
- 💻 Clean and simple user interface
- ⚡ Electronics-focused shopping layout

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎨 Design

The website uses:

- Sticky navigation bar
- Product cards
- Buttons and hover effects
- Responsive layout
- CSS Grid for product display
- Mobile-friendly design

The product section uses a responsive grid that changes to a single-column layout on smaller screens.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `home.html`.
4. Run the file using a browser or Live Server.

## 📄 Pages

### Home
Introduces ElectroShop and provides a button to explore products.

### Explore
Displays available electronic products with their prices and descriptions.

### About
Provides information about ElectroShop and its goal of offering quality electronics at affordable prices.

### Contact
Contains a contact form with fields for name, email, subject, and message.

### Login
Provides a simple login form with email and password fields.

## 📱 Responsive Design

The website is designed to work on desktop and mobile screens using CSS media queries.
